# Copywriting Tone Reference

Platform-specific product description tones and examples for automatic content generation.

---

## 拼多多 / 低价电商

**语气特征：** 亲切、接地气、有促销感
**描述风格：** 简短有力、突出优惠、感叹号和emoji

```
"家人们冲！🔥 限时秒杀价到手只要XX，错过等一年！"
"这个价格真的杀疯了，赶紧下手🛒"
"质量杠杠的，买过的都说好👍"
"真·白菜价，囤就完事了"
"手慢无！这个价只限今天"

服装：   "版型超正！穿上立马显瘦10斤"
数码：   "这价格还要啥自行车，能用就行？不，还好用！"
食品：   "一口下去酥掉渣，追剧必备零嘴"
家居：   "租房党闭眼入，这个价格还要啥自行车"
```

## 淘宝 / 综合电商

**语气特征：** 专业、详细、有信任感
**描述风格：** 突出材质/功能/售后，适当用"亲"

```
"亲～这款XX真的绝了，面料超柔软，夏天穿巨凉爽"
"现货秒发，喜欢的亲不要错过哦～"
"性价比超高，质量完全对得起这个价格"
"好评如潮，回头客超多，闭眼入不会错"
"亲亲，这款是今年的爆款，卖超多单了呢"

服装：   "亲～纯棉面料，透气不闷热，夏天穿太舒服了"
数码：   "亲～这款性能杠杠的，日常办公追剧完全够用"
食品：   "亲～纯手工制作，0添加，老人小孩都能放心吃"
家居：   "亲～简约风格超百搭，放在家里瞬间提升格调"
```

## 京东 / 3C数码 / 品牌店

**语气特征：** 参数清晰、理性、专业
**描述风格：** 突出规格、性能、质保

```
"搭载XX处理器，性能释放充分，日常使用/游戏体验流畅"
"官方正品，享全国联保，品质有保障"
"X英寸2K屏，观影办公都很舒适"
"续航实测X小时，彻底告别电量焦虑"
"通过XX认证，符合国家XX标准"

电脑：   "搭载第X代i5处理器，16G内存，办公/设计/轻度游戏全能应对"
手机：   "X英寸OLED屏，XmAh大电池，XX快充，日常使用无短板"
家电：   "一级能效，每天不到一度电，节能又环保"
配件：   "官方正品，兼容XX/XX/XX设备，即插即用"
```

## 小红书 / 种草风格

**语气特征：** 朋友推荐感、真实分享
**描述风格：** 第一人称、带个人体验、自然语气

```
"用了半个月真的回不去了！！姐妹们一定要试试"
"听劝！这个真的可以冲，谁用谁知道"
"被问了800遍的链接来了，真的巨好用"
"小个子福音！这个版型我吹爆"
"谁用谁好看，我已经安利给全办公室了"

服装：   "梨形身材的天菜！遮肉显瘦，我直接回购了三个色"
美妆：   "黄皮素颜涂也好看！就是这种奶呼呼的豆沙色"
家居：   "租房党都给我买！几十块钱幸福感直接拉满"
食品：   "减脂期也能吃的零食！本甜食脑袋狂喜"
```

## 抖音 / 快手

**语气特征：** 快节奏、有冲击力
**描述风格：** 短句、痛点切入、促单话术

```
"还在用普通款？试试这个，差距不是一点点"
"敢说不好用算我输！拍一发三，赶紧上车"
"懂行的都在抢，再犹豫就没了"
"点击左下方小黄车，直接带走"
"不废话，直接说价格——XX，上链接！"

日用：   "家里还在用这个的赶紧换！差距太大了"
美妆：   "油皮姐妹看过来！这款上脸真的绝了"
食品：   "不好吃你来找我！真的香迷糊了"
数码：   "这个配置卖这个价？老板是不是疯了"
```

## 闲鱼 / 二手平台

**语气特征：** 真实个人卖家、随意
**描述风格：** 简单描述、说明成色、理由自然

```
"买来就用过两次，跟新的一样，闲置回血"
"公司发的用不上，全新未拆封，便宜出了"
"搬家清仓，都是自用正品"
"冲动消费买多了，出给有缘人"
"买来试了一下不合适，仅拆封"

数码：   "用了一个月，换了新款所以出，成色很新，无划痕"
服装：   "买小了，吊牌还在，全新转给合适的姐妹"
家居：   "家里买了两个，一个用不上，全新未拆"
美妆：   "色号买错了，就用了一次，半价出"
```

## 知乎 / 专业社区

**语气特征：** 理性分析、有深度
**描述风格：** 逻辑清晰、引用数据或经验

```
"从参数来看这款在同价位确实能打"
"实测体验下来，最大的感受是..."
"如果追求性价比，这个价位段它是最均衡的选择"
"综合来看，它在XX方面有优势，但在XX方面有妥协"
```

## 微信公众号 / 微商

**语气特征：** 有温度、故事感
**描述风格：** 软文风格、情感共鸣

```
"第一次拿到手就被质感惊艳到了"
"用了之后才发现，原来生活可以这么简单"
"不是所有XX都叫XX，这款真的不一样"
"忙了一天回到家用它，感觉一切都值了"
```

## 通用商品类型话术侧重速查

| 商品类型 | 关键词 | 示例短句 |
|---------|--------|---------|
| 服装/穿搭 | 版型、面料、显瘦、搭配 | "微胖也能穿"、"巨显腿长" |
| 数码/3C | 性能、续航、参数、兼容 | "续航一整天"、"性能拉满" |
| 美妆/护肤 | 肤质、效果、成分、色号 | "油皮亲妈"、"素颜也能涂" |
| 食品/零食 | 口感、食材、口味、份量 | "酥掉渣"、"追剧必备" |
| 家居/日用 | 实用性、颜值、质量 | "租房党必备"、"幸福感拉满" |
| 母婴/儿童 | 安全、材质、舒适 | "A类纯棉"、"宝宝穿超安心" |
| 虚拟/服务 | 便捷、省时、效果 | "每天10分钟"、"一站式搞定" |
